## About

An early CSS-focused project: a single-page food brand site built around a looping full-screen
background video, with product imagery layered over it. The goal was practising visual
composition — layering, contrast and readable text over moving media.

## What's in it

```
Burgur/
├── index.html       page markup
├── style.css        layout, overlay and typography
├── Food_Back.mp4    full-screen background video (~7.5 MB)
├── coke.png · fries.png   product imagery
└── color pallet     the palette used, kept as a reference
```

## Running locally

```bash
python -m http.server 8000
```

## Notes

> The background video is ~7.5 MB and loads eagerly, so first paint is slow on a poor
> connection. Compressing it, adding a poster frame, or serving a WebM alternative would
> be the first real optimisation here.

This is one of my earlier projects and I've deliberately left it as-is — it's a useful
marker of where I started.
